## landing page

1. prefer use lib `motionjs` to static design, prefer create a firstly entrance animation to attract the user's attention but not play repeatly when user back to top and browser again.
2. If metrial limited support, like one picture and one paragraph, use two columns layout to display the content. the situation repeat items like this, use two columns layout to display the content and exchange the position of picture and paragraph to keep the content balance.
3. experiment with layering elements to make some unique design.(for example, multiple layers for two text can make a magazine style title)
